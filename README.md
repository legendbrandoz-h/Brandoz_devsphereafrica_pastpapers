# DevSphere Africa Past Papers

A web application designed for searching, viewing, and managing past examination papers. Built with Vite, React, TypeScript, and Firebase.

## 🚀 Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend / Database:** Firebase (Firestore, Authentication)
* **Runtime / Package Manager:** Bun (or Node.js / npm)

## 🛠️ Local Development

### 1. Prerequisites
Ensure you have [Bun](https://bun.sh) (or Node.js) installed.

### 2. Setup
Clone the repository and install dependencies:

```bash
git clone [https://github.com/legendbrandoz-h/Brandoz_devsphereafrica_pastpapers.git](https://github.com/legendbrandoz-h/Brandoz_devsphereafrica_pastpapers.git)
cd Brandoz_devsphereafrica_pastpapers
bun install
